# Examples

This directory contains practical examples and tutorials to help you learn how to build your own CoPilot-enhanced applications.

## 📚 Available Examples

### 1. Basic MCP Setup

**Location**: `basic-mcp-setup/`

Learn the fundamentals of setting up Model Context Protocol with GitHub Copilot.

**What you'll learn**:
- Creating an MCP configuration file
- Connecting to GitHub MCP server
- Testing the integration
- Basic usage patterns

**Level**: Beginner  
**Time**: 15 minutes

---

### 2. Full Application Example

**Location**: `../src/`

Explore the complete FastAPI application that demonstrates all concepts in action.

**What you'll learn**:
- Creating FastAPI endpoints
- Adding proper documentation
- Type hints for better AI suggestions
- Testing with Copilot Chat
- Real-world MCP integration

**Level**: Intermediate  
**Time**: 45 minutes

## 💡 Contributing Examples

Have a great example to share? We'd love to include it!

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines on submitting examples.

### Example Contribution Guidelines

Your example should include:

- **README.md** - Clear instructions and explanations
- **Source Code** - Well-commented and clean code
- **Requirements** - Dependencies and prerequisites
- **Expected Output** - What users should see when they run it
- **Learning Objectives** - What concepts are covered

### Ideas for Examples

We're looking for examples covering:

- [ ] Custom MCP server implementation
- [ ] Integration with different services (Slack, Discord, etc.)
- [ ] Multi-language implementations (TypeScript, Go, Java)

- [ ] Testing AI-assisted code
- [ ] CI/CD with Copilot

## 📖 Learning Path
